# LoomGit 织仓

面向 Windows x64 的 Git 图形客户端。

## 下载与运行

[查看最新版及下载链接](https://github.com/Wanchenrui/loomgit-releases/releases/latest)

- **免安装版**完整解压 ZIP，再双击 `LoomGit 织仓.exe`。
- **安装版**下载并运行 EXE，按向导完成安装。

操作 Git 仓库需要 Git for Windows 2.41 或更新版本。

## 自动更新

应用启动时和运行期间会自动检查更新，也可在 **设置 → 软件更新** 手动检查。安装版可下载后重启安装，免安装版可下载新版 ZIP。

使用 0.2.0 或更早版本的用户，请先手动升级一次。
